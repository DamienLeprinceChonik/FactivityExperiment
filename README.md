# FactivityExperiment
For a M1 thesis (under the supervision of Bastien Blain - Université Paris Panthéon Sorbonne), I am running an experiment on the effect of verbal factivity on the perception of news headlines and demand for news. To this extent, I created an experiment using the library JsPsych which is run through JATOS server. 

WARNING: The experiment can be tested only with the jsPsych library loaded. To test the experiment, please launch the index file in the same folder that the Images file and jsPsych file.
